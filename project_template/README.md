This is a skeleton project for your final CS 401 project.

You can *add your HTTP server and Wi-Fi code* to this directory as normal .py files.

The main code is in `app.py`. Remember that renaming `app.py` to `main.py` will cause your code to automatically run each time the device starts up - but it can also complicate accessing the device should you need to modify the code. You should only do this AFTER you have fully tested your code manually.
